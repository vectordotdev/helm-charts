Legacy Vector Helm charts

This archive preserves the 24 stable chart packages previously published at https://packages.timber.io/helm/latest. The packages and their SHA-256 checksums are unchanged. No new chart versions will be added here.

Move an existing repository

If your repository is named vector, update its URL with the commands below. Substitute your existing repository name if it is different. 

helm repo add vector https://helm.vector.dev/legacy/ --force-update
helm repo update vector

Keep your existing chart name, pinned version, release name, namespace, and values. This change only updates the download location; it does not upgrade your installation. For example, to download the archived agent chart: 

helm pull vector/vector-agent --version 0.17.2

Chart versions in the current repository at helm.vector.dev have a different history. The same chart name and version can identify different packages, so use this archive when preserving a legacy installation. Upgrading to the current chart requires a separate migration.

These historical charts retain their original Kubernetes APIs, image references, and defaults. Archiving them does not establish compatibility with current clusters or availability of the referenced images.

Nightly chart snapshots are not included. For current releases and installation instructions, see the Vector Helm documentation.
